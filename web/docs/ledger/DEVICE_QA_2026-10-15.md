2. First upload failed (fake storage was not reachable from the phone — environment, fixed with `adb reverse 3912`); the app showed "upload failed", Retry succeeded, document attached with a thumbnail.
3. Submit created the leave; the DB holds a private `cld:` reference, manifest row `attached`, claimed.
4. Employee opened "1 document" → authenticated read 200. App restart: session restored, the leave still listed.
5. Manager (separate sign-in) saw it under Team Approvals, opened the document (200), and approved it; DB shows `approved`, document set unchanged.
